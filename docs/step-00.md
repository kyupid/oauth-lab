# 스텝 0 — 역할 지도

## 네 개의 역할

```
  Resource Owner            Client                Authorization Server      Resource Server
  (나, 브라우저 앞)          (데모 앱 :9002)         (AS :9000)               (RS :9001)
       │                       │                        │                        │
       │  ① 로그인 눌러        │                        │                        │
       ├──────────────────────>│                        │                        │
       │                       │  ② /authorize 로 리다이렉트                     │
       │<──────────────────────┤                        │                        │
       │  ③ 브라우저가 AS 방문 · 로그인 · 동의           │                        │
       ├───────────────────────────────────────────────>│                        │
       │  ④ redirect_uri?code=... 로 리다이렉트          │                        │
       │<───────────────────────────────────────────────┤                        │
       │  ⑤ 브라우저가 code 를 앱에 전달                 │                        │
       ├──────────────────────>│                        │                        │
       │                       │  ⑥ POST /token (code → access token)            │
       │                       ├───────────────────────>│                        │
       │                       │<───────────────────────┤                        │
       │                       │  ⑦ Authorization: Bearer <token>                │
       │                       ├────────────────────────────────────────────────>│
       │                       │<────────────────────────────────────────────────┤
```

## 두 개의 채널 — 이게 OAuth 보안의 거의 전부다

| | front channel | back channel |
|---|---|---|
| 누가 요청하나 | **브라우저** (③④⑤) | **앱 서버** (⑥⑦) |
| 엔드포인트 | `/authorize` | `/token` |
| 값이 어디 남나 | URL → 히스토리, 리퍼러, 서버 로그, 어깨너머 | 어디에도 안 남음 |
| 그래서 | **code** 만 보낸다 (짧게 쓰고 버릴 것) | **token** 을 보낸다 |

> ✍️ **왜 code 를 한 번 거치나?**
> access token 을 front channel 로 바로 주면(= implicit grant) 토큰이 브라우저 URL 에 남는다.
> code 는 (a) 수명이 짧고 (b) 1회용이고 (c) client_secret 또는 PKCE 없이는 토큰으로 못 바꾼다.
> → 스텝 8에서 implicit 을 직접 만들어 돌려보고 지운다.
